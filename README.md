# Itshaala Website

## About the Project

Itshaala Website is a web application project developed to practise Java web development and understand how frontend pages interact with a Java backend.

The project is currently under development as I continue learning Java web technologies and improving my programming skills.

**Project Status:** Work in Progress

## Technologies Used

- Java
- Java Servlets
- JSP (JavaServer Pages)
- HTML
- CSS
- MySQL
- JDBC
- Maven
- Apache Tomcat

## Project Structure

The project follows a Java web application structure and includes:

- **Java Classes:** Backend application logic.
- **Servlets and Controllers:** Handle incoming requests and application flow.
- **JSP Pages:** Render dynamic web pages.
- **HTML and CSS:** Structure and style the user interface.
- **Database Configuration:** Supports database connectivity where implemented.
- **`web.xml`:** Web application configuration.
- **`pom.xml`:** Maven dependency and build configuration.

## Current Progress

The project contains Java source files, web pages, and application configuration files.

Some parts of the application are incomplete and may require debugging, further implementation, and testing.
